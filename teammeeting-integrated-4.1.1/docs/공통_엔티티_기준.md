# 공통 엔티티 기준

Spring Boot 4.1.1 / Java 17 / Lombok 기준. A와 B는 이 소스를 함께 사용합니다.

## 공통 규칙

- 기본 패키지: com.example.teammeeting
- 모든 id: Long, IDENTITY 자동 증가, setter 없음
- Lombok: @Getter, @Setter, @NoArgsConstructor; id는 @Setter(AccessLevel.NONE)
- JPA: jakarta.persistence, 참조는 LAZY ManyToOne, 자동 cascade와 양방향 컬렉션 없음
- 모든 관계는 필수이며 Meeting.confirmedPlace만 선택 사항
- MeetingStatus: OPEN 또는 CONFIRMED, 문자열로 저장; 기본 OPEN
- 확정 전 confirmedDate, confirmedStartTime, confirmedEndTime, confirmedPlace는 null
- 엔티티에 @Data를 사용하지 않음

## 추가 규칙

User.email은 소문자로 정규화하고 passwordHash에 비밀번호 해시를 저장합니다. 문자열 길이는 email 254, 회원 name 40, 모임 name 80, inviteCode 16, 장소 name 80, memo 300입니다.

Availability의 member와 meetingDate는 같은 모임이어야 합니다. Vote의 사용자와 장소도 해당 모임에 속해야 합니다. 이는 엔티티 관계만으로 모두 보장되지 않으므로 각 담당자의 업무 Service에서 검증합니다.
